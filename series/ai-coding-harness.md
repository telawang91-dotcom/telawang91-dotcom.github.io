这套系列关注 **Coding Agent 如何理解代码库、组织任务产物、执行工具并完成验证闭环**。内容会覆盖 Codebase Context、Workspace、Spec → Design → Tasks → Code、脚本校验、无交互评测与权限控制。

重点不是某个 IDE 插件，而是 Coding Agent 背后的 Harness 与工程运行时。
