这套系列关注 **Agent 的执行过程如何被系统接管和约束**。核心是状态机、LangGraph、Supervisor / Manager Agent、产物驱动工作流，以及 Retry、Rollback、Replan 和多 Agent 上下文共享。

目标是把“LLM 自己决定下一步”逐步改造成一个可观察、可恢复、可测试的 Agent Runtime。
